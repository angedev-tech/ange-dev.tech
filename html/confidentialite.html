Données transmises par les formulaires

Le formulaire de contact demande un nom, une adresse e-mail, un téléphone, un sujet et un message. Le formulaire de projet peut aussi recueillir une entreprise, le type de solution, des fonctionnalités, un délai, un numéro WhatsApp, une description et un fichier PDF facultatif.

Ces informations servent à répondre aux messages et à examiner les demandes de projet. Ne transmettez pas de données sensibles qui ne sont pas nécessaires à cette prise de contact.

Transmission par Formspree

Les formulaires transmettent leurs données au service Formspree configuré dans le code afin de traiter la soumission. Les données de compte, les notifications, les lieux de traitement et les durées applicables doivent être vérifiés dans la configuration et la documentation actuelle de ce fournisseur avant publication de cette politique.

Stockage local et services externes

Le choix du thème clair ou sombre est mémorisé dans le stockage local du navigateur. Le site charge également des polices et des icônes depuis Google Fonts et Cloudflare. Leur chargement implique une requête vers ces fournisseurs.

Aucun outil d’analyse d’audience ni de publicité n’est configuré dans le code examiné. La présence de cookies ou d’autres traitements déclenchés par des services tiers doit être vérifiée dans la configuration de production.
